# Miranda Empório de Bebidas — V7

Esta versão inclui o cardápio público, a Central Administrativa, relatórios e o novo Cardápio do Atendente.

## Novos endereços

- Cardápio do atendente: `atendente/login.html`
- Após login: `atendente/index.html`

O pedido feito pelo atendente entra na mesma conta da mesa e aparece normalmente para os clientes que acessarem o QR Code.

Leia `docs/ALTERACOES-V7.md` e publique também o novo `firestore.rules`.
